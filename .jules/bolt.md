## 2026-11-09 - Memoization in React Native FlatList\n**Learning:** Defining inline components for `renderItem` in `FlatList` creates new component instances on every render. This destroys performance because React has to unmount and remount each component. Additionally, passing inline arrow functions directly in JSX (like `renderItem={useCallback(...)}`) violates the Rules of Hooks.\n**Action:** Always define list items as standalone components *outside* the parent component, use `React.memo` to prevent unnecessary re-renders, define callbacks with `useCallback` *at the top level* of the component body, and define the `renderItem` function at the top level of the component, wrapped in `useCallback`.
