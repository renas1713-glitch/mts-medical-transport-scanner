
## 2025-02-12 - Extracted TripCard component and memoized handlers to avoid re-renders
**Learning:** Extracting an inline functional component mapped in a `FlatList` (or similar component) into a `React.memo` component, alongside wrapping handler functions generated in the parent in `useCallback` greatly improves performance by avoiding expensive component recreations and re-renders when parent state updates. Temporary patch files (`patch.diff`, `replace.sh`) generated by diff-based edits must be properly cleaned (e.g., using `rm` and unstaging them if they accidentally slip into Git's staged area).
**Action:** When extracting components wrapped in `React.memo` for list rendering, place the component definition entirely outside of the parent function. Additionally, rigorously review any temporary workspace files used during editing to ensure they are deleted and not accidentally staged prior to commit.
