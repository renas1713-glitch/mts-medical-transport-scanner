## 2024-05-18 - Memoized FlatList Render Item\n**Learning:** In React Native, passing an inline arrow function as `renderItem` to `FlatList` breaks memoization and can cause severe performance issues, especially when items re-render. `useCallback` should be used for `renderItem` and `keyExtractor`.\n**Action:** Always wrap `renderItem` and `keyExtractor` in `useCallback` when using `FlatList`. Memoize expensive calculations passed directly in JSX using `useMemo`.
