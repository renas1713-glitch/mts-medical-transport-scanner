## 2023-10-27 - FlatList Performance Bottleneck\n**Learning:** In React Native, inline function definitions for `renderItem` inside a `FlatList` cause unnecessary re-renders of all items whenever the parent component updates. This is a common performance bottleneck in React Native apps.\n**Action:** Always wrap the `renderItem` function and its dependencies (like event handlers) in `useCallback` to maintain referential equality and prevent re-rendering.
