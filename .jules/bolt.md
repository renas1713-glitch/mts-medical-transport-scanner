## 2024-07-06 - [App Component Re-render Optimization]
**Learning:** The root `App` component in this React Native app was calculating derived state (`stats`) on every single render, and passing a new un-memoized function `renderTripCard` down to a `FlatList` component on every render. This meant that the `FlatList` could unnecessarily re-render its list items anytime `App` re-rendered. In React Native, `FlatList` performance is highly dependent on memoized `renderItem` and `keyExtractor` functions.
**Action:** Use `useMemo` for derived states like array aggregations and `useCallback` for `renderItem` functions passed to `FlatList`. Ensure that dependencies passed to `useCallback` are also memoized (e.g., `handleStartNavigation` also needs to be wrapped in `useCallback`).
