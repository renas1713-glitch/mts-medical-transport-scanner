## 2025-02-27 - React Native FlatList Rendering & Animations Allocations
**Learning:** React Native's `FlatList` component depends on `renderItem` identity to perform pure component optimization effectively. If `renderItem` is defined inside a functional component without `useCallback`, it's recreated on every render, invalidating optimizations. Additionally, static array/object variables defined inside a component are recreated each render; this is exceptionally costly if the component rerenders frequently, like inside a 60FPS Camera animation view.
**Action:** Always wrap `renderItem` and related navigation callbacks in `useCallback`. Move constant arrays (like templates/tips) outside the component function so they are only allocated once. Calculate expensive view model derivations using `useMemo` instead of doing array loops (e.g. `reduce`/`filter`) inline in JSX.
