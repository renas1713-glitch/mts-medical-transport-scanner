Wait, the most obvious performance opportunity here is that `useNativeDriver: true` is properly set, however, `scanLineAnim` and `guideOpacity` animations should be stopped in the cleanup function of `useEffect` to prevent memory leaks and continue running in the background when the component unmounts.\n**Action:** Add `return () => anim.stop()` to `useEffect` hooks with `Animated.loop`.
