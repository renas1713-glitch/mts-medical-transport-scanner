## 2024-05-20 - App Performance Analysis\n**Learning:** The FlatList in App.tsx defines its `renderTripCard` function inline inside the component body, which causes a new function reference to be created on every render. Because this component manages state (`currentScreen`, `trips`, `activeScannedData`), any state change causes a re-render and re-creation of this function. Additionally, the `handleStartNavigation` function is not memoized.\n**Action:** Use `useCallback` for `renderTripCard` and `handleStartNavigation` to prevent unnecessary re-creations and re-renders of list items.
